ไม่ต้อง Import SQL

1) สำรอง /public_html/qa/
2) อัปโหลดไฟล์ภายใน qa/ ไปทับ /public_html/qa/
3) ห้ามทับ includes/config.php
4) Ctrl+F5

ทดสอบหน้าแผน:
- Summary เต็มความกว้างเมื่อเป็นผู้ใช้ดูอย่างเดียว
- มีเมนูนำทางภายในหน้า
- มีหัวข้อ “ความเชื่อมโยงของแผน”
- Target ที่มี Mission/Strategy/Focus ต้องแสดง chain ครบ
- ถ้า Target ไม่มี Focus ต้องแสดง “ยังไม่เชื่อมจุดเน้น”
- สถานะ active ต้องแสดงเป็น “ใช้งานอยู่”

ทดสอบหน้าผู้ใช้:
- Edit user ต้องแสดงสถานะรหัสผ่านปัจจุบันเป็น masked
- ไม่แสดงรหัสผ่านเดิมจริง เพราะฐานข้อมูลเก็บ password_hash
- พิมพ์รหัสใหม่แล้วกด “แสดง/ซ่อน” ได้
- บันทึกโดยปล่อยช่องรหัสใหม่ว่าง ต้องไม่เปลี่ยนรหัสผ่านเดิม
