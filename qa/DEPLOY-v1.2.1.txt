QA v1.2.1 — Phase 3.6.1
โครงสร้าง 5 ฝ่าย + ปรับเมนูปริมาณงาน สพฐ.

สำคัญ: ต้อง Import SQL
======================
1) สำรองฐาน anusarn_qa
2) Import:
   anusarn_qa_v1.2.1_phase3.6.1_five_divisions.sql

SQL จะ:
- เพิ่ม STUDENT_AFFAIRS = กลุ่มบริหารกิจการนักเรียน
- map กิจกรรมย่อย สพฐ. 155 ไปฝ่ายกิจการนักเรียน

3) สำรอง /public_html/qa/
4) แตก qa-website-v1.2.1-php56.zip
5) นำไฟล์ภายใน qa/ ไปทับ /public_html/qa/
6) ห้ามเขียนทับ /public_html/qa/includes/config.php
7) Ctrl+F5

สิ่งที่ควรเห็น
==============
- "จัดสรรงบ 5 ฝ่าย"
- Dashboard มีสี 5 ฝ่าย:
  วิชาการ=น้ำเงิน
  งบประมาณ=เขียว
  บุคคล=ม่วง
  ทั่วไป=ส้ม
  กิจการนักเรียน=ชมพู/กุหลาบ
- User Management เลือกฝ่ายกิจการนักเรียนได้
- โครงการเลือกฝ่ายกิจการนักเรียนได้
- Master สพฐ. 155 map ไปกลุ่มบริหารกิจการนักเรียน
- เมนูเดิม "กิจกรรมย่อย สพฐ. / ปริมาณงาน" ไม่อยู่ใต้แผนและงบประมาณแล้ว
- เมนูใหม่อยู่ใต้ "สารสนเทศและระบบ" ชื่อ:
  "ปริมาณงาน สพฐ. / แบบ 10"

หมายเหตุ
=======
เมนูปริมาณงาน สพฐ. เป็นรายงานสำหรับงานแผน/งบประมาณ/ผู้บริหารและการรายงานต่อ สพฐ.
ไม่ใช่ขั้นอนุมัติโครงการ และไม่ใช่เมนูประเมิน สมศ. โดยตรง
