QA v1.1.3 — Division Color System

ไม่ต้อง Import SQL เพิ่ม

สีประจำฝ่าย
===========
วิชาการ      = น้ำเงิน
งบประมาณ    = เขียว
บุคคล        = ม่วง
ทั่วไป        = ส้ม
ส่วนกลาง     = เทา

อัปเดต
=======
1. สำรอง /public_html/qa/
2. แตก qa-website-v1.1.3-php56.zip
3. นำไฟล์ภายในโฟลเดอร์ qa/ ไปทับ /public_html/qa/
4. ห้ามเขียนทับ /public_html/qa/includes/config.php
5. Ctrl+F5

ไฟล์หลักที่เปลี่ยน
=================
- /includes/bootstrap.php
- /includes/sidebar.php
- /dashboard.php
- /budget/allocation.php
- /budget/allocation-detail.php
- /assets/css/app.css
- /includes/footer.php

ทดสอบ
=====
1. Dashboard > งบประมาณรายฝ่าย
   ต้องเห็นวิชาการน้ำเงิน / งบประมาณเขียว / บุคคลม่วง / ทั่วไปส้ม

2. จัดสรรงบ 4 ฝ่าย
   - แถบภาพรวมแต่ละฝ่ายคนละสี
   - ช่องกรอกวงเงินแต่ละฝ่ายมีสีของฝ่าย
   - ตาราง 4 ฝ่ายมีแถบสีด้านซ้าย

3. เปิด "ดูฝ่าย"
   หน้ารายละเอียดต้องใช้ Accent สีเดียวกับฝ่ายนั้น

หมายเหตุ
=======
สีใช้ช่วยแยกฝ่ายเท่านั้น ทุกจุดยังมีชื่อฝ่ายกำกับเพื่อให้อ่านได้แม้ผู้ใช้แยกสีได้ยาก
