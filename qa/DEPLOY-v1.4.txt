QA v1.4 — Phase 4.2 Project Activity Management

ต้อง Import SQL
===============
1) สำรองฐาน anusarn_qa
2) Import:
   anusarn_qa_v1.4_phase4.2_project_activity_management.sql

อัปเดต
=======
3) สำรอง /public_html/qa/
4) อัปโหลดไฟล์ภายใน qa/ ไปทับ /public_html/qa/
5) ห้ามทับ includes/config.php
6) Ctrl+F5
7) Logout/Login ใหม่

Workflow ใหม่
=============
ผู้รับผิดชอบโครงการ / หัวหน้าฝ่าย / admin
  → เปิดโครงการ
  → จัดการกิจกรรม
  → มอบหมายผู้รับผิดชอบรายกิจกรรม

ผู้รับผิดชอบกิจกรรม
  → เมนู "กิจกรรมที่รับผิดชอบ"
  → เปิดกิจกรรมของตน
  → รายงานความก้าวหน้า
  → กรอกผลผลิต / ผลลัพธ์
  → ปัญหา / ขั้นตอนถัดไป
  → เพิ่มหลักฐาน
  → 100% = กิจกรรมเสร็จสิ้น

ข้อจำกัด
========
- ไม่ให้ผู้รับผิดชอบกิจกรรมแก้งบ/อนุมัติโครงการ
- การมอบหมายกิจกรรมเปิดหลังโครงการได้รับอนุมัติ
  เพราะการแก้ DRAFT/REVISION เดิมจะสร้าง activity ใหม่จากรายการงบประมาณ
- "กิจกรรมภายใต้โครงการ" คนละความหมายกับ "รหัสกิจกรรมย่อย สพฐ. 151-155"
